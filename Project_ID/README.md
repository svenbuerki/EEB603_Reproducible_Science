# Content of the project

**The directories are numbered to follow the data and analysis flow**, so reading
this listing from top to bottom is reading the project from the field to the
journal. The content is as follows:

- `01_Raw_Data` contains all input data (and metadata) exactly as collected.
  **It is written once and never edited**, by a script or by hand.
- `02_Processed_Data` contains cleaned and transformed data. Everything in here
  is produced by a script in `03_Scripts`, so it can always be rebuilt.
- `03_Scripts` contains the numbered scripts that do the work, run in order.
- `04_Output` contains intermediate and output files (for example simulation
  outputs and fitted models).
- `05_Figures_and_Tables` contains the figures and tables generated by the
  analyses, as they appear in the manuscript.
- `06_Reports` contains R Markdown files that document the analysis or report
  on results.
- `07_MS` contains the manuscript.
- `R_functions` contains R scripts with function definitions. **It carries no
  number on purpose**: its contents are called at every stage, so any number
  would be misleading.

Single digits are left-padded with a zero (`01`, not `1`) so that the
directories and scripts sort in the order they run.
