# Chapter 5 -- PART A exercise material

`Messy_Project.zip` is the deliberately mismanaged project folder that students
inherit in the group activity
[You Have Just Inherited This Project](https://svenbuerki.github.io/EEB603_Reproducible_Science/Chapters.html#inheritproject).

**Everything in it is synthetic.** The measurements, the site coordinates, the
landowner names and the phone numbers are invented for teaching purposes. No
real person, landowner or population is described. Every defect in the folder
is planted on purpose.

`make_messy_project.R` regenerates both the folder and the zip:

```
Rscript Exercises/Chapter_5/make_messy_project.R
```
